# 实体清单

> spectra-admin 全部持久化实体完整字典。源码当前共 87 个带 `@TableName` 的 Entity（不含 `BaseEntity`）。实体按业务模块归属，Core 只维护系统核心、安全、调度和监控实体；可选模块不把自己的实体下沉到 Core。

## 当前实体归属

| 模块 | `@TableName` Entity 数量 | 归属说明 |
|---|---:|---|
| `spectra-core` | 42 | 用户、认证、授权、组织、系统配置、审计、调度和服务监控 |
| `spectra-notification` | 7 | 通知请求、模板、任务、投递、收件箱和偏好 |
| `spectra-upload` | 5 | 文件类型、资产、上传会话、分片和业务引用 |
| `spectra-workflow` | 2 | Flowable 业务表单定义和版本 |
| `spectra-oa` | 31 | OA 申请、请假、报销、采购、资产、合同、文档等领域 |

实体清单由源码 `@TableName` 扫描和文档检查共同校验；新增或删除 Entity 时必须同步本文件及对应 schema 说明。

## 时间字段约定

所有实体中需要持久化的日期、时间和日期时间字段统一使用 `Instant`，数据库字段统一使用 `TIMESTAMP(6) WITH TIME ZONE`。通知免打扰时间，以及 OA 合同、资产、库存、采购、报销、考勤等日期字段均遵循此约定；对应 VO 按展示语义使用 `LocalDate`、`LocalTime` 或 `LocalDateTime`。

## 核心 — 单体调度

五张基础调度表由 `spectra-config` 的 Flyway V4 一次性迁移创建，操作审计表由 Flyway V6 创建；Flyway V10 注册文件上传清理的 `SYSTEM/SINGLETON` 任务定义。上述调度表均位于 `spectra_core`，实体继承 `BaseEntity`。`deleted` 字段只为公共实体结构兼容保留，调度逻辑使用定义状态、执行状态和版本 CAS，不以该字段过滤或判断生命周期。

| Entity | 表名 | 关键字段 |
|---|---|---|
| `SchedulerJobEntity` | `scheduler_job` | jobKey、handlerKey、jobType、runScope、definitionStatus、desiredState、scheduleKind、cronExpression/fixedDelayMs、executionPolicy、parameters、revision |
| `SchedulerExecutionEntity` | `scheduler_execution` | jobId、fireKey、triggerType、status、版本/处理器快照、计划/租约时间、attemptNo、resultSummary、originalExecutionId、resolutionStatus |
| `SchedulerLoopRuntimeEntity` | `scheduler_loop_runtime` | jobId、sessionKey、instanceId、status、心跳/租约时间、周期/处理/失败计数、stateReason |
| `SchedulerControlCommandEntity` | `scheduler_control_command` | jobId、targetRuntimeId、commandType、status、idempotencyKey、reason、请求/应用/完成时间、结果 |
| `SchedulerLoopErrorEntity` | `scheduler_loop_error` | jobId、instanceId、runtimeId、errorFingerprint、errorCode、status、出现/抑制计数、lastContext、解决信息 |
| `SchedulerOperationAuditEntity` | `scheduler_operation_audit` | jobId、executionId、operationType、status、idempotencyKey、reason、申请/完成时间、结果；仅 OPS/SYSTEM 操作 |

所有调度时间列使用 `TIMESTAMP(6) WITH TIME ZONE`，Java 类型使用 `Instant`；JSONB 字段显式使用 `PgJsonbTypeHandler`。唯一约束分别保护任务键、执行 fire key、循环会话键、控制命令幂等键和循环错误指纹。
