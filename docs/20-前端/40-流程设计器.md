# 流程设计器 — logicflow-plugin-flowable

> 基于 LogicFlow 的 BPMN 2.0 流程设计器插件，为 Flowable 提供可视化建模、属性配置和 BPMN XML 导入导出能力。

## 文档定位

流程设计器的代码仓库是 [`logicflow-plugin-flowable`](https://github.com/yangxj96/logicflow-plugin-flowable)，npm 包名为 `@yangxj96/logicflow-plugin-flowable`。本页是面向使用者和集成开发者的完整说明；Spectra 中的宿主集成、后端接口和业务流程边界记录在 [[30-流程建模插件]]。

| 项目 | 内容 |
|---|---|
| 包名 | `@yangxj96/logicflow-plugin-flowable` |
| 当前版本 | `0.1.1` |
| 依赖 | LogicFlow 2.x、Vue 3、Element Plus |
| 输出 | ESM、CJS、TypeScript 声明和 CSS |
| 协议 | Apache-2.0 |

## 能力概览

- 注册常用 BPMN 事件、任务、网关、子流程和序列流节点。
- 提供可拖拽的 DND 节点面板和流程、节点、连线属性面板。
- 支持 Flowable 扩展属性，例如 `flowable:assignee`、`flowable:class` 和候选用户组。
- 支持从 BPMN XML 导入，并优先恢复 BPMN DI 坐标和连线路径。
- 支持将 LogicFlow 画布导出为 Flowable 可部署的 BPMN 2.0 XML。
- 通过事件把表单、用户、用户组、Java 类和流程选择器交给宿主业务系统实现。

## 安装

```bash
pnpm add @yangxj96/logicflow-plugin-flowable
```

宿主项目需要提供 LogicFlow 和 Vue 运行环境：

| 依赖 | 版本 |
|---|---|
| `@logicflow/core` | `^2.1.11` |
| `@logicflow/extension` | `^2.1.11` |
| `element-plus` | `^2.13.5` |
| `vue` | `^3.5.30` |

## 初始化

插件不创建外层页面布局，宿主需要准备画布、DND 面板和属性面板容器。面板及其父级必须有明确高度：

```html
<div class="flowable-editor">
  <aside id="dnd-panel" class="flowable-panel"></aside>
  <main id="graph" class="flowable-canvas"></main>
  <aside id="property-panel" class="flowable-panel"></aside>
</div>
```

```css
.flowable-editor {
  display: grid;
  grid-template-columns: 240px minmax(0, 1fr) 320px;
  width: 100%;
  height: 720px;
  min-height: 0;
}

.flowable-panel,
.flowable-canvas {
  min-width: 0;
  min-height: 0;
  overflow: hidden;
}
```

注册插件并挂载两个面板：

```typescript
import LogicFlow from "@logicflow/core";
import Flowable, {
  type FlowablePluginOptions,
  type PickerType
} from "@yangxj96/logicflow-plugin-flowable";
import "@yangxj96/logicflow-plugin-flowable/style.css";

const lf = new LogicFlow({
  container: document.querySelector("#graph") as HTMLElement,
  plugins: [Flowable.Plugin],
  pluginsOptions: {
    [Flowable.Plugin.pluginName]: {
      panel: {
        dnd: document.querySelector("#dnd-panel") as HTMLElement,
        property: document.querySelector("#property-panel") as HTMLElement
      },
      pickers: ["form", "user", "group", "javaClass", "process"] as PickerType[]
    } satisfies FlowablePluginOptions
  }
});

lf.render();
```

初始化后插件会注册 BPMN 节点、设置默认序列流、启用子流程容器、挂载右键菜单，并在画布渲染后挂载面板。若宿主不需要内置面板，可以只注册 `Flowable.Plugin`。

## Picker 选择器

`pickers` 声明由宿主业务系统提供的选择器类型。插件只发出选择请求，不负责调用业务 API 或实现弹窗：

| 类型 | 用途 |
|---|---|
| `form` | Flowable 表单或表单定义 |
| `user` | 指定人、候选用户 |
| `group` | 用户组、候选组 |
| `javaClass` | 服务任务的 Java 实现类 |
| `process` | 调用活动引用的流程 |

```typescript
type PickerRequestPayload = {
  pickerType: PickerType;
  field: string;
  currentValue: string;
  multiple: boolean;
  nodeId?: string;
  nodeType?: string;
  resolve: (value: string, label?: string) => void;
};

lf.on("property:picker", (payload: PickerRequestPayload) => {
  openBusinessPicker({
    type: payload.pickerType,
    multiple: payload.multiple,
    currentValue: payload.currentValue,
    onConfirm(items) {
      payload.resolve(
        items.map(item => item.value).join(","),
        items.map(item => item.label ?? item.value).join(",")
      );
    }
  });
});
```

多选值使用逗号分隔；值写入 BPMN 属性，label 只用于面板显示。没有加入 `pickers` 的类型会降级为普通文本输入。

## DND 与属性面板

DND 面板按事件、任务、网关和子流程分组提供节点。属性面板根据当前选择自动切换：点击空白区域编辑流程属性，点击节点编辑节点属性，点击连线编辑连线属性。

常用属性类型包括 `string`、`textarea`、`number`、`boolean`、`select`、`expression` 和 `picker`。节点和连线属性保存在 LogicFlow 元素的 `properties.form` 中，导出 XML 时读取最新值。

## BPMN XML 导入导出

导出当前画布：

```typescript
const xml = Flowable.toBpmnXml(lf);
```

导出内容包括流程级属性、`isExecutable`、节点和 Flowable 扩展属性、序列流、条件表达式、脚本内容、文档说明和 BPMN DI 坐标。脚本和条件表达式使用 CDATA，避免特殊字符破坏 XML。

从 BPMN XML 导入：

```typescript
const result = Flowable.fromBpmnXml(xmlString, lf);

if (!result.success) {
  console.error(result.message);
}
```

导入流程会校验 `definitions` 根元素，查找第一个 `process`，读取节点和连线属性，优先恢复 BPMN DI 坐标；没有坐标时执行基础网格布局。导入接口依赖浏览器的 `DOMParser`，应在浏览器环境中调用。

## 支持的 BPMN 元素

| 分类 | 当前支持 |
|---|---|
| 事件 | 开始、结束、中间捕获、中间抛出、边界事件 |
| 任务 | 用户、服务、脚本、接收、手工、业务规则任务 |
| 网关 | 排他、并行、包容网关 |
| 子流程 | 嵌入式子流程、展开子流程、调用活动 |
| 连线 | 序列流、条件序列流、默认序列流 |

事件网关、复杂网关、事件/事务子流程、Pool、Lane 和 Message Flow 仍属于后续增强范围，使用前应以插件仓库的实际版本和变更记录为准。

## 开发与构建

```bash
pnpm install
pnpm run dev
pnpm run build

cd examples
pnpm install
pnpm dev
```

在 Spectra 中联调时，流程设计器代码仍在 `logicflow-plugin-flowable` 仓库维护；本地插件构建产物由 `spectra-ui` 的本地依赖接入。后端 Flowable 负责流程部署和运行，设计器负责建模与 BPMN XML 生成，两者通过 XML 和业务接口衔接。
