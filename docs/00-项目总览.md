# Spectra 项目总览

> 光谱平台 — 一个后端 API 服务和一个 Web 管理后台，并配套流程建模插件的全栈系统。

> 后端当前基线为单体多模块、单租户、非 SaaS：`spectra-launch` 是唯一 Spring Boot 组合根，`spectra-core` 是始终装配的核心能力，包含系统管理、统一通知和文件上传；OA、Workflow 是可选业务模块。应用层不提供租户上下文、租户切换或租户隔离；Flowable 表中的 `tenant_id_` 仅属于引擎兼容字段。

模块装配由 `spectra-launch` 显式完成。`spectra.modules.oa.enabled` 和 `spectra.modules.workflow.enabled` 只控制可选业务模块是否装配，`spectra-core` 始终启用；`spectra.notification.enabled` 仅控制通知业务功能，不控制 Core 模块装配；模块之间不通过服务注册、远程配置或服务发现连接。

## 目录结构

```
spectra/
├── spectra-admin/          ← 后端 API 服务
│   ├── spectra-config/     ← 统一配置文件（所有 application-*.yml）
│   ├── spectra-common/     ← 公共契约、值对象、安全端口、审计/健康协议（保留少量历史技术桥接）
│   ├── spectra-framework/  ← 框架与安全技术层（MVC/JSON/缓存/Redis/MyBatis配置）
│   ├── spectra-modules/    ← 业务模块聚合层
│   │   ├── spectra-core/   ← 必选核心：用户/权限/系统/调度/监控/审计/通知/上传
│   │   ├── spectra-oa/     ← OA：申请/请假/协同/报销/采购/资产/考勤/日历/通讯录/合同/文档/会议/公告/报表
│   │   ├── spectra-workflow/ ← 工作流：Flowable 流程引擎
│   └── spectra-launch/     ← 启动入口（Spring Boot Application）
├── spectra-ui/             ← Web 管理后台
└── logicflow-plugin-flowable/     ← LogicFlow BPMN 2.0 流程建模插件
```

| spectra-ui (Web) | 5173 |
