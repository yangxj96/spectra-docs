# 脚本工具

> 根仓库保留行政区划数据导入和网站文档同步工具。普通开发直接使用 mise 和各子项目的原生命令。

## 可直接使用

以下脚本都从仓库根目录执行，并通过脚本位置解析仓库根目录，不依赖个人盘符：

| 脚本 | 是否修改文件/环境 | 用途 |
|---|---|---|
| `scripts/import-regions.ps1` | 只写入明确指定的隔离数据库 | 受 `SPECTRA_REGION_IMPORT=true` 保护的行政区划导入 |
| `scripts/sync-website-docs.ps1` | Preview 不修改；Apply 修改网站生成目录 | 同步项目文档、附件、侧边栏和清单 |

```powershell
pwsh -NoProfile -File .\scripts\import-regions.ps1
$website = 'D:\path\to\website'
pwsh -NoProfile -File .\scripts\sync-website-docs.ps1 --website-root $website --mode Preview
```

日常启动和安装依赖不需要这些脚本；它们也不负责激活 mise 或替代 `mise exec`：

- `import-regions.ps1` 只在明确需要导入行政区划数据且目标是隔离数据库时运行。
- `sync-website-docs.ps1` 只在发布网站文档时运行。

仓库脚本和测试使用 PowerShell 7，无需设置可执行位。需要运行脚本测试时使用：

```powershell
pwsh -NoProfile -File .\scripts\tests\import-regions.tests.ps1
pwsh -NoProfile -File .\scripts\tests\sync-website-docs.tests.ps1
pwsh -NoProfile -File .\scripts\tests\open-source-docs.tests.ps1
```

## 本机配置

- 后端配置：`spectra-admin/.mise.local.toml`，从 `.mise.local.toml.example` 复制。
- Web 配置：`spectra-ui/.env.development`，从 `.env.example` 复制。
- 证书：`spectra-admin/files/ssl/keystore.p12`，仅保存在本机。

这些文件可能包含密码、Token、私钥或证书私钥；脚本只读取项目模板和路径，不读取或输出本机敏感值。

## 工具要求

| 工具 | 用途 |
|---|---|
| PowerShell 7.6+、`git`、`rg` | 根仓库脚本执行和检查 |
| Python 3.12+ 标准库 | 网站同步实现 |
| mise | 固定 Java、Node 和 pnpm 版本 |
| OpenSSL、`keytool` | 本机证书检查或生成 |

普通开发终端只需保证 `mise` 在 PATH 中，并在对应子项目目录执行 `mise exec -- ...`。

## 网站文档同步

网站同步入口为 `scripts/sync-website-docs.ps1`，会把现有 CLI 参数转发给 Python 实现并返回其退出码：

```powershell
$website = 'D:\path\to\website'
pwsh -NoProfile -File .\scripts\sync-website-docs.ps1 `
  --website-root $website `
  --mode Preview

pwsh -NoProfile -File .\scripts\sync-website-docs.ps1 `
  --website-root $website `
  --mode Apply --prune-legacy --build
```

Preview 不修改网站仓库；Apply 不自动执行 Git commit 或 push。同步会拒绝 `.env*`、`.mise.local.toml`、P12/JKS/PEM/KEY 以及名称包含 secret/token/password 的文件。
