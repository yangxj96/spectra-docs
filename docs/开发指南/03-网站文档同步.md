# 网站项目文档同步

`spectra-docs` 是项目文档源仓库，网站仓库负责发布。同步工具在本机运行，只修改网站受控生成目录，不自动执行 Git commit 或 push；不依赖 CI 或固定的个人路径。

## 文档分区

| 源文档 | 网站目录 |
|---|---|
| `docs/00-项目总览.md` | `docs/pages/spectra/` |
| `docs/前端/` | `docs/pages/spectra-ui/` |
| `docs/后端/` | `docs/pages/spectra-admin/` |
| `docs/开发指南/` | `docs/pages/spectra-guide/` |
| `docs/部署运维/` | `docs/pages/spectra-ops/` |
| `docs/流程设计器/` | `docs/pages/logicflow-flowable/` |
| `docs/后端/10-后端模块/permission-catalog.yaml` | `docs/public/spectra-admin/` |
| 网站仓库 `docs/pages/blogs/` | 保持原位置，不参与同步 |

`docs/AI速查/` 保留在源仓库供 AI Agent 使用，但不属于任何发布分区，永不复制到网站。本机配置、`.env*`、私钥、Token、密码和证书私钥也永不复制。

同步清单中的 `sidebarTitleOverrides` 用于为侧边栏设置独立显示名，键为分区内的源文件相对路径。正文和页面标题可以保留 `BPMN`、`Redis`、`API` 等技术名称，但侧边栏应配置面向读者的中文名称；未配置映射时才使用文档一级标题。

## Bash 命令

入口为 `scripts/sync-website-docs.sh`。`--website-root` 可以显式指定网站仓库目录；省略时默认使用源仓库同级的 `yangxj96-website` 目录。

```bash
website='/path/to/website'
./scripts/sync-website-docs.sh \
  --website-root "$website" \
  --mode Preview

./scripts/sync-website-docs.sh \
  --website-root "$website" \
  --mode Apply --prune-legacy --build
```

Preview 不修改 website；Apply 使用生成清单清理过期页面。生成区有手工差异时默认拒绝覆盖，确认差异全部来自同步工具后才使用：

```bash
./scripts/sync-website-docs.sh \
  --website-root "$website" \
  --mode Apply --allow-dirty-project-docs --build
```

日常同步可以直接复用上一次清单：

```bash
./scripts/sync-website-docs.sh \
  --website-root "$website" \
  --mode Apply --build
```

## 检查 website 差异

```bash
git -C "$website" status --short --branch
git -C "$website" diff --stat -- docs/pages/spectra-admin docs/pages/logicflow-flowable docs/public/spectra-admin .vitepress/generated
git -C "$website" diff -- docs/pages/blogs
pnpm --dir "$website" run docs:build
```

若网站仓库位于受 Git `safe.directory` 保护的路径，先按本机 Git 策略将该目录标记为可信，再执行上述检查；不要把个人绝对路径写入仓库文档。

确认项目文档差异无误、博客差异为空后，再在 website 仓库手动 commit 和 push。

## 安全边界

- 脚本使用 POSIX 路径并校验所有源/目标路径不越出仓库根目录。
- `.env*`、`.mise.local.toml`、P12/JKS/PEM/KEY 和名称包含 secret/token/password 的文件会被拒绝或跳过。
- `blogs` 永远不会进入删除计划。
- Apply 失败会恢复受控生成目录；脚本不执行 Git commit 或 push。

```text

```
