## 实现与完整调用方

`PageFrom` 删除无参数 `toPage()`，请求排序项改为独立的 `PageOrderFrom`，保留 HTTP 的 `column`、`asc` 字段形状。每个 SQL 用例显式传入字段映射，输出新建的 MyBatis 排序项；不再共享请求列表或可变项。

白名单拒绝未知字段、敏感列、表达式、客户端别名、空/null 字段、null 项和重复目标列。保留原始输入使 `id--` 不会被 MyBatis setter 清理成 `id`。null/空集合保留服务端默认排序；固定排序入口对非空排序返回 400。异常消息不回显原始载荷。

共有 **22 个 SQL 转换入口 + 10 个固定排序入口**，另有在线用户分页组装器内部防线。逐项清单及字段映射见 [分页排序契约](../../后端/30-规范/06-分页排序契约.md)。

- Core：用户、部门直属成员、区域、通知收件箱、通知请求/任务/投递、四个文件分页入口；固定排序涉及在线用户、角色、审计、Quartz 作业/历史、通知模板/分组。
- OA：资产、日程、物品、会议、通用申请、报销、文档、请假、采购、合同、公告；通讯录固定排序。
- Workflow：待办与已办固定排序。未展开 OA/Workflow 的独立业务治理。
- 部门成员查询将公开字段映射到 `user_record`；通知投递映射到 `d` / `t`，客户端不提供表别名。
- CodeGraph 在 admin 与 UI 分别查询定义和影响。索引中 `toPage` 仍显示旧版本的 21 个调用；当前源码 `rg` 查到 22 个，包含继承 `PageFrom` 的部门成员入参，已全部迁移。索引不能替代当前源码。
- UI 的 `BasePageParams` 有 25 个图索引调用；`rg -n 'orders|OrderItem|sort-change' src types` 仅发现类型声明，没有当前页面发送自定义排序。无需本轮 Web 实现修改，未展开 B08。
