# 模块清单

> 所有子项目及其模块的一句话职责描述。

## 后端模块 (spectra-admin)

### 基础层

| 模块 | 路径 | 职责 |
|---|---|---|
| spectra-config | `spectra-config/` | 统一配置文件，所有 application-*.yml 集中管理 |
| spectra-common | `spectra-common/` | 公共契约：BaseEntity、DTO、值对象、审计/健康协议；保留少量已登记的历史技术桥接 |
| spectra-framework | `spectra-framework/` | 技术基础设施：MVC、JSON、Redis、缓存、MyBatis、加密和 Actuator 健康适配 |

### 启动与自动配置

| 模块 | 路径 | 职责 |
|---|---|---|
| spectra-launch | `spectra-launch/` | Spring Boot 唯一启动入口和组合根，只负责模块装配与校验 |
| spectra-starter | `spectra-starter/` | Maven 聚合层；其叶子模块提供 Security/Log 技术启动器 |

### 业务模块

| 模块 | 路径 | 职责 |
|---|---|---|
| spectra-core | `modules/spectra-core/` | 必选核心：用户/认证/角色/权限/组织/系统配置/统一审计、安全变更 outbox、审计归档编排、健康聚合和单体调度 |
| spectra-notification | `modules/spectra-notification/` | 统一通知：请求、模板、任务、投递、站内收件箱和用途×渠道偏好 |
| spectra-oa | `modules/spectra-oa/` | OA 办公：资产/考勤/日历/通讯录/合同/文档/会议/公告/报表 |
| spectra-upload | `modules/spectra-upload/` | 文件上传：本地存储 + S3，分片上传 |
| spectra-workflow | `modules/spectra-workflow/` | 工作流：Flowable 流程引擎，审批/任务/历史 |

## 模块依赖关系

```
spectra-oa ──→ spectra-core + workflow.api + common.port.file
spectra-workflow ──→ common + framework
spectra-upload ──→ common + framework
spectra-notification ──→ common

spectra-launch ──→ core + optional modules + starter leaf modules
                 ├─→ spectra-modules（仅聚合，不提供运行时能力）
                 └─→ spectra-starter（仅聚合，不提供运行时能力）

core 不依赖可选业务模块；未来 `spectra-erp` 由 launch 装配，不修改 Core。
```
