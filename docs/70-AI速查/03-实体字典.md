# 实体字典

> 源码当前 66 个带 `@TableName` 的 Entity 字段速查表（不含 BaseEntity）。

## 公共基类

### BaseEntity

> 所有实体的公共父类

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | UUID (String) | 主键，UUID v7 |
| `createdBy` | String | 创建人 ID |
| `createdAt` | Instant | 创建时间 |
| `updatedBy` | String | 更新人 ID |
| `updatedAt` | Instant | 更新时间 |
| `deleted` | Instant | 软删除时间（NULL=未删除） |
| `version` | Integer | 乐观锁版本号 |

## 时间字段约定

实体持久化时间统一使用 `Instant`，数据库统一使用 `TIMESTAMP(6) WITH TIME ZONE`；请求 `From` 使用 ISO 8601 `String`，响应 VO 按展示语义使用 `LocalDate`、`LocalTime` 或 `LocalDateTime`，由 `TimeMapper` 处理时区转换。

## OA 模块

文档管理新增实体：`Document`（`oa_document`，标题/目录/状态/可见范围/所有者）、`DocumentFolder`（`oa_document_folder`，目录树）和 `DocumentVersion`（`oa_document_version`，文件版本链与当前版本标识）。

合同管理新增实体：`Contract`（`oa_contract`，合同编号/相对方/金额/期限/生命周期状态）、`ContractVersion`（`oa_contract_version`，合同文件版本链）和 `ContractMilestone`（`oa_contract_milestone`，履约节点与完成状态）。
