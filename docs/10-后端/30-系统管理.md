# 系统管理

> 核心系统管理功能：部门、区域、字典、菜单、系统配置、操作日志。模块路径：`spectra-core/system`。

## 实体总览

| Entity | 表说明 |
|---|---|
| `Department` | 组织架构（树形） |
| `Region` | 行政区划（树形） |
| `Menu` | 系统菜单（树形） |
| `DictGroup` | 字典分组 |
| `DictItem` | 字典项 |
| `Configured` | 配置表 |
| `SysConfig` | 系统参数 |
| `OperationLog` | 操作日志 |

## Department（部门）

树形结构，支持多级组织架构。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | UUID | 主键 |
| `name` | String | 部门名称 |
| `parentId` | UUID | 父部门 ID |
| `sort` | Integer | 排序 |
| `leader` | String | 负责人 |
| `phone` | String | 联系电话 |
| `status` | Integer | 状态 |

## Region（区域）

行政区划数据，省/市/区县三级树形结构。

## Menu（菜单）

系统菜单树，支持任意层级嵌套。菜单只负责导航和角色可见性，页面组件由 Web 前端静态路由定义。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | UUID | 主键 |
| `name` | String | 菜单名称 |
| `pid` | UUID | 父菜单 ID |
| `menuType` | MenuType | `DIRECTORY` 或 `MENU` |
| `routeName` | String | `MENU` 对应的唯一 Vue Router 路由名 |
| `icon` | String | 图标 |
| `sort` | Integer | 排序 |

约束：`DIRECTORY` 不配置路由名并可拥有子节点；`MENU` 必须配置路由名且是叶子节点。Java Entity、From、VO 和数据库均已移除 `path`、`component`、`layout`、`hide`、`metadata`。

菜单写入请求遵循全局 `SNAKE_CASE` JSON 约定，使用 `menu_type`、`route_name` 字段；后端保存 From 同时兼容 `menuType`、`routeName`，避免旧客户端因字段命名差异丢失菜单类型。

运行时接口：

| 接口 | 权限 | 说明 |
|---|---|---|
| `GET /menu/tree` | `MENU:QUERY` | 菜单管理和 RBAC 使用的完整管理树 |
| `GET /menu/current` | 已认证 | 合并当前用户启用角色的菜单并自动补齐祖先目录 |

菜单、用户角色关系、角色和角色菜单关系查询均显式添加 `deleted IS NULL`，不依赖 MyBatis-Plus 对 `Instant` 软删除字段的隐式过滤；角色菜单保存会拒绝软删除菜单。

## DictGroup / DictItem（数据字典）

两级结构：DictGroup 是字典分组（如"性别"），DictItem 是字典项（如"男"/"女"）。

## Configured / SysConfig（系统配置）

- `Configured` — 配置表，支持 Key-Value 对
- `SysConfig` — 系统参数，支持按模块分类

## OperationLog（操作日志）

记录用户操作行为，用于审计追溯。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | UUID | 主键 |
| `userId` | UUID | 操作用户 |
| `module` | String | 操作模块 |
| `action` | String | 操作类型 |
| `target` | String | 操作对象 |
| `ip` | String | 操作 IP |
| `userAgent` | String | 客户端信息 |
| `requestParams` | Text | 请求参数 |
| `responseResult` | Text | 响应结果 |
| `duration` | Long | 执行耗时(ms) |

## Controller

| Controller | 说明 |
|---|---|
| `DepartmentController` | 部门 CRUD + 树形查询 |
| `RegionController` | 区域查询 |
| `MenuController` | 菜单 CRUD + 完整管理树 + 当前用户授权树 |
| `DictController` | 字典管理 |
| `ConfiguredController` | 配置表管理 |
| `ServiceMonitorController` | 服务监控（OSHI） |
| `CryptoController` | 密钥管理（RSA 密钥对生成/公钥查询） |

## Service

| Service | 说明 |
|---|---|
| `DepartmentServiceImpl` | 部门管理 |
| `RegionServiceImpl` | 区域管理 |
| `MenuServiceImpl` | 菜单管理 |
| `DictServiceImpl` / `DictGroupServiceImpl` / `DictItemServiceImpl` | 字典管理 |
| `ConfiguredServiceImpl` | 配置表管理 |
| `SysConfigServiceImpl` | 系统参数管理 |
| `OperationLogServiceImpl` | 操作日志 |
| `ServiceMonitorServiceImpl` | 服务监控（基于 OSHI 6.9.1） |
