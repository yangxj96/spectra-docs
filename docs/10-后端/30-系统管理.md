# 系统管理

> 核心系统管理功能：部门、区域、字典、菜单、系统配置、操作日志和单体调度管理。模块路径：`spectra-core/system`、`spectra-core/scheduler`。

## 实体总览

| Entity | 表说明 |
|---|---|
| `Department` | 组织架构（树形） |
| `Region` | 行政区划（树形） |
| `Menu` | 系统菜单（树形） |
| `DictGroup` | 字典分组 |
| `DictItem` | 字典项 |
| `Configured` | 配置表 |
| `SysConfig` | 系统参数 |
| `OperationLog` | 操作日志 |

## Department（部门）

树形结构，支持多级组织架构。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | UUID | 主键 |
| `name` | String | 部门名称 |
| `parentId` | UUID | 父部门 ID |
| `sort` | Integer | 排序 |
| `leader` | String | 负责人 |
| `phone` | String | 联系电话 |
| `status` | Integer | 状态 |

## Region（区域）

行政区划数据，省/市/区县/乡镇街道/村级五级树形结构。

## Menu（菜单）

系统菜单树，支持任意层级嵌套。菜单只负责导航和角色可见性，页面组件由 Web 前端静态路由定义。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | UUID | 主键 |
| `name` | String | 菜单名称 |
| `pid` | UUID | 父菜单 ID |
| `menuType` | MenuType | `DIRECTORY` 或 `MENU` |
| `routeName` | String | `MENU` 对应的唯一 Vue Router 路由名 |
| `icon` | String | 图标 |
| `sort` | Integer | 排序 |

约束：`DIRECTORY` 不配置路由名并可拥有子节点；`MENU` 必须配置路由名且是叶子节点。Java Entity、From、VO 和数据库均已移除 `path`、`component`、`layout`、`hide`、`metadata`。

菜单写入请求遵循全局 `SNAKE_CASE` JSON 约定，使用 `menu_type`、`route_name` 字段；后端保存 From 同时兼容 `menuType`、`routeName`，避免旧客户端因字段命名差异丢失菜单类型。

运维管理下的 `文件管理` 目录由 `V11__complete_file_upload_management.sql` 写入，与 `系统维护` 同级；其子菜单包括文件上传、文件资产、上传任务、文件引用和文件类型策略，对应 Web 静态路由 `/devops/file/upload`、`/devops/file/assets`、`/devops/file/upload-tasks`、`/devops/file/references` 和 `/devops/file/types`。菜单仅负责入口可见性，上传接口权限、管理写权限和文件资产访问权限仍由 Core 文件能力及业务引用上下文控制。

运行时接口：

| 接口 | 权限 | 说明 |
|---|---|---|
| `GET /menu/tree` | `MENU:QUERY` | 菜单管理和 RBAC 使用的完整管理树 |
| `GET /menu/current` | 已认证 | 合并当前用户启用角色的菜单并自动补齐祖先目录 |

菜单、用户角色关系、角色和角色菜单关系查询均显式添加 `deleted IS NULL`，不依赖 MyBatis-Plus 对 `Instant` 软删除字段的隐式过滤；角色菜单保存会拒绝软删除菜单。

## DictGroup / DictItem（数据字典）

两级结构：DictGroup 是字典分组（如"性别"），DictItem 是字典项（如"男"/"女"）。

## Configured / SysConfig（系统配置）

- `Configured` — 配置表，支持 Key-Value 对
- `SysConfig` — 系统参数，支持按模块分类

首次初始化会通过受控白名单向 `spectra_core.sys_config` 写入以下非敏感配置：

| Key | 类型 | 说明 |
|---|---|---|
| `system.name` | TEXT | 系统名称 |
| `system.short-name` | TEXT | 系统简称；为空时回退为系统名称 |
| `system.logo` | TEXT | Logo 地址或文件标识，可为空 |
| `system.default-locale` | TEXT | 系统默认语言，当前支持 `zh-CN` / `en-US`；初始化用户使用此值 |
| `system.default-timezone` | TEXT | 系统默认时区，必须是有效 IANA 时区；初始化用户使用此值 |
| `security.profile` | SELECT | 初始化时选择的安全策略，当前为 `STANDARD` / `STRICT` |

系统状态与引导状态共用 `spectra_core.sys_system_state`：`state_key=SYSTEM` 管理首次初始化生命周期，`state_key=SYSTEM_GUIDE` 管理初始化后的 DEV_OPS 系统设置引导，分别使用各自的状态值，不能合并为一个状态判断。DEV_OPS 首次登录完成系统引导时创建初始化根部门，并将 DEV_OPS 设置为该部门的主成员；引导完成后，`crypto.*`、`notification.*` 和 `copyright.*` 的运行时配置写入 `spectra_core.sys_config`。

系统设置引导当前负责以下运行时策略：

| Key | 类型 | 说明 |
|---|---|---|
| `crypto.enabled` | BOOL | 是否启用接口请求加解密；启用时自动生成 RSA 密钥 |
| `notification.enabled` | BOOL | 是否启用 Core 内置统一通知业务功能 |
| `notification.address-encryption-key` | TEXT | 通知外部地址 AES-GCM 密钥，由引导自动生成 |
| `notification.sensitive-payload-key` | TEXT | 通知敏感载荷 AES-GCM 密钥，由引导自动生成 |
| `notification.allowed-link-prefixes` | TEXT | 消息中心允许的站内路由前缀 |
| `notification.cleanup.enabled` | BOOL | 是否清理终态通知中的敏感密文 |
| `copyright.enabled` | BOOL | 是否显示管理页面底部版权 |
| `copyright.name` | TEXT | 底部版权名称 |
| `copyright.url` | TEXT | 底部版权名称点击后的 HTTP/HTTPS 跳转地址 |

`DEFAULT_PASSWORD` 已移除：当前新增用户和密码重置使用随机临时凭证，不再使用共享默认密码。管理员重置密码的明文只在本次接口响应返回，临时密码默认 24 小时过期且首次登录后必须修改；数据库、Redis、SSL 证书、S3 等启动前置或外部服务凭据仍使用环境变量或密钥管理系统。

初始化接口不接受任意配置键；密码、Token、第三方凭据和私钥不写入这组配置。

## OperationLog（操作日志）

记录用户操作行为，用于审计追溯。

普通操作事件先在业务事务内写入 `spectra_core.sys_operation_log_outbox`，由 Core 调度 worker 按租约、重试和幂等约束写入 `sys_log`；消费失败不会删除事件，达到上限后进入 `DEAD_LETTER` 等待人工处置。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | UUID | 主键 |
| `userId` | UUID | 操作用户 |
| `module` | String | 操作模块 |
| `action` | String | 操作类型 |
| `target` | String | 操作对象 |
| `ip` | String | 操作 IP |
| `userAgent` | String | 客户端信息 |
| `requestParams` | Text | 请求参数 |
| `responseResult` | Text | 响应结果 |
| `duration` | Long | 执行耗时(ms) |
| `outboxEventId` | UUID | 来源 outbox 事件 ID，用于消费幂等和追溯 |

## Controller

| Controller | 说明 |
|---|---|
| `DepartmentController` | 部门 CRUD + 树形查询 |
| `RegionController` | 区域查询 |
| `MenuController` | 菜单 CRUD + 完整管理树 + 当前用户授权树 |
