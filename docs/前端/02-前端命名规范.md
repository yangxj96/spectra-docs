# 前端命名规范

> 本页只维护命名和目录约定；启动、路由、请求和组件的实现细节分别见 [[03-前端启动与路由]]、[[05-前端请求与安全通信]] 和 [[07-前端公共组件与文件能力]]。

> 命名主线已按 [[开发指南/04-工作区工程标准|工作区工程标准]] 于 2026-10-03 统一；现有代码的集中迁移和验收状态见 [[开发指南/05-集中治理与验收|治理入口]]。

> 来源：[[00-项目总览|项目 VitePress 文档]]
>
> 适用于 **Vue 3 + Vite + TypeScript + Element Plus** 项目（spectra-ui）。

## 总体原则

1. 页面与组件目录使用 `PascalCase`，目录入口为 `index.vue`；独立组件使用 `PascalCase.vue`。
2. 普通 TypeScript、API、Store 与 Hook 文件使用 `kebab-case`，技术分层目录沿用 `api`、`components`、`hooks`、`views` 等既有名称。
3. 组件和类型标识使用 `PascalCase`；普通函数与自有状态使用 `camelCase`，API 导出对象沿用 `UserApi` 等项目约定。
4. JSON 和生成的 API 字段保留实际 `snake_case`。入口、生成文件或外部约定要求的名称明确适用范围，不按普通文件规则强行改名。

## 推荐目录结构

```
src/
├── api/              # 接口定义层
├── assets/           # 静态资源
├── components/       # 全局公共组件
├── directive/        # 自定义指令
├── hooks/            # 组合式函数
├── plugin/
│   ├── element/      # Element Plus 全局配置
│   ├── request/      # HTTP 封装
│   ├── router/       # 路由配置
│   └── stores/       # Pinia 初始化
├── utils/            # 通用工具类
├── views/            # 页面组件
├── App.vue
└── main.ts
```

## 文件命名规则

| 类型 | 规范 | 示例 |
|---|---|---|
| 普通 TS/JS | `kebab-case.ts` | `message-helper.ts` |
| Vue 组件 | `PascalCase.vue` | `UserTable.vue` |
| 页面/组件目录入口 | `PascalCase/index.vue` | `System/User/index.vue`、`UserEdit/index.vue` |
| composables | `use-xxx.ts` | `use-message.ts` |
| API 文件 | `xxx-api.ts` | `role-api.ts` |
| Store 文件 | `xxx-store.ts` | `user-store.ts` |

### 禁止

```
MessageHelper.ts        # ❌ PascalCase 文件名
messageHelper.ts        # ❌ camelCase 文件名
roleApi.ts              # ❌ camelCase 文件名
```

## API 层规范

```ts
// role-api.ts
export const RoleApi = {
    list() {},
    create() {},
    update() {}
};

import { RoleApi } from "@/api/role-api";
```

## Store 规范

```ts
// user-store.ts
export const useUserStore = defineStore("user", {});
```

## 类型命名

- 类型名：`PascalCase`
- API 数据与端点类型以后端导出及生成结果为准，不按页面需要擅自改变协议字段。
- 页面状态类型按实际职责命名；DTO、VO 等后缀用于表达对应职责，不要求所有前端模型映射后端 Entity。

## 总结

| 类型 | 规范 |
|---|---|
| 页面/组件目录 | `PascalCase`，入口 `index.vue` |
| 技术分层目录 | 沿用既有 `api`、`hooks` 等名称 |
| 普通 TS 文件 | `kebab-case` |
| Vue 组件 | `PascalCase.vue` |
| composables | `use-xxx.ts` |
| API 文件 | `xxx-api.ts` |
| Store | `xxx-store.ts` |
