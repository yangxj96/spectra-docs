## 跨层数据流

```text
用户操作
   │
   ├─ spectra-ui 页面 / 公共组件
   │      ├─ Pinia 保存会话、菜单、加密和业务 UI 状态
   │      └─ src/plugin/request 统一发送 HTTP / 二进制请求
   │
   ├─ 工作流设计页面
   │      ├─ LogicFlow 维护画布模型
   │      ├─ logicflow-plugin-flowable 提供 BPMN 元素和 XML 转换
   │      └─ WorkflowApi 调用流程定义、任务和部署接口
   │
   └─ spectra-admin
          ├─ 返回授权菜单、权限和业务数据
          ├─ 接收 BPMN XML 并交给 Flowable 部署
          └─ 负责真正的安全、事务、持久化和流程运行
```

## 维护规则

- 新增页面时，同时检查 `src/views/`、`src/plugin/router/modules/`、菜单权限和本目录页面矩阵。
- 新增 API 时，只从 `src/plugin/request/api.ts` 或上传适配器进入，不在业务页面直接使用 Axios、`fetch` 或 `XMLHttpRequest`。
- 修改请求字段、权限编码或流程 XML 契约时，联动更新对应的前端文档、后端 API 文档和测试。
- 修改流程节点、属性 Schema 或导入导出逻辑时，优先更新流程设计器对应专题页，再更新本页导航。
- 文档同步时只同步“项目总览、前端、后端、开发指南、部署运维、流程设计器”分区；`AI速查/` 保持源仓库专用。
