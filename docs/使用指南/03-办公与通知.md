# 办公与通知

办公自动化页面位于 `/oa` 下。OA 模块是否可用由后端模块装配和当前用户权限共同决定；页面没有出现在菜单中时，先检查模块是否启用和用户授权。

## 申请和审批

当前 OA 页面包含申请类型、请假申请、费用报销、采购申请和审批中心等入口。不同申请使用各自的业务字段和状态，但通常遵循以下操作顺序：

1. 在业务菜单进入列表页，确认当前数据范围。
2. 创建申请并填写必填信息。
3. 保存草稿后检查附件、金额、日期或关联数据。
4. 提交申请进入审批流程；提交后是否允许编辑、撤回或取消由业务状态决定。
5. 在审批中心查看待办和已办，在业务详情中查看审批结果。

请假、报销和采购申请与工作流模块有明确的业务回调：流程任务完成后会回写对应 OA 业务状态；流程终止、撤回和取消也会触发各自的业务状态迁移。不要只根据前端按钮是否显示判断审批是否完成。

## 日历、会议和通讯录

OA 还包含日历管理、会议管理和通讯录入口：

- 日历用于维护可查询的日程记录。
- 会议用于创建会议、处理参会响应、签到和记录。
- 通讯录用于查找组织中的联系人，显示范围由权限和数据范围控制。

这些页面的创建、编辑、响应和查询权限由后端业务接口执行。

## 合同、文档、资产和办公用品

- 合同管理维护合同及里程碑信息。
- 文档管理支持文档、文件夹和版本管理，并通过文件引用关联实际文件。
- 资产管理维护资产信息，也可以从采购业务产生资产记录。
- 办公用品维护用品和库存相关操作。

业务页面使用文件引用而不是直接暴露物理存储路径。删除或下载文件前，系统会根据业务引用、用户权限和文件状态再次判断。

## 公告与统一通知

公告通知页面用于维护 OA 公告。消息中心展示当前用户可见的站内消息；统一通知模块还提供通知请求、模板、渠道、受控发送和运行概览等管理入口。

通知发送是否成功取决于通知配置、模板、渠道和异步投递状态。出现“请求已创建但用户未收到”的情况时，管理员应先查看通知请求状态、投递记录、重试次数和渠道配置，而不是重复提交同一业务请求。

## 报表

报表管理提供按部门查看和导出数据的入口。报表结果受当前用户数据范围影响，导出文件应按照组织的信息安全要求保存和传递。
