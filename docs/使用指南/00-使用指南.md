## 系统中的角色

平台中的操作权限由后端授予，前端菜单只是权限结果的展示：

- 普通用户可以访问分配给自己的业务菜单，并在业务范围内创建或处理数据。
- 业务管理员可以维护部分业务数据、组织关系或申请类型，具体范围由角色和数据范围决定。
- 系统管理员可以维护用户、角色、菜单、系统配置和运行管理入口。
- 运维和审计人员可以看到服务监控、缓存监控、安全审计、在线用户等受控页面。

同一个用户可以拥有多个 RoleAssignment。角色被移除、账号停用、会话撤销或数据范围改变后，前端重新请求权限时会反映新的授权状态。

## 使用前检查

1. 后端健康检查可以访问 `https://127.0.0.1:4004/api/actuator/health`。
2. Web 管理后台可以打开 `https://localhost:5173`。
3. 系统已经完成首次初始化，至少有一个可登录用户。
4. 当前用户处于可登录状态，并且已经获得需要使用的菜单和权限。
