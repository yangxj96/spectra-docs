# Backend Utility and Cross-cutting Capability Convergence Matrix

> Task18 inventory and migration record. Paths and callers were verified from the
> `spectra-admin` working tree on 2026-09-08. `docs/superpowers/` remains ignored;
> this file is force-added only with the Task18 documentation commit.

## Decision rules

| Rule | Decision |
| --- | --- |
| Pure foundation | Keep only JDK-oriented, stateless behavior in `spectra-common.foundation`; no Servlet, Spring, persistence, Lombok, or Guava imports. |
| Security algorithm | Keep one implementation per algorithm in `spectra-common.security.crypto`, split by symmetric/asymmetric/digest capability. Framework Web may use these implementations; business modules use feature-owned adapters. |
| Web adapter | Servlet request interpretation belongs to `spectra-framework.web`; it must not remain in common. |
| Domain helper | Authentication, notification, OA file reference, and workflow behavior stays in the owning feature package. No generic common alias or fallback package is retained. |
| Bean/lifecycle capability | `NameFillExecutor` remains an injected Spring component in `framework.assembler`; it is not converted into a static utility or a singleton mutable cache. |
| Feature converter | MapStruct converters remain under the feature's `javabean.converter`; only `GlobalMapperConfig` and `TimeMapper` are shared from `framework.serialization.mapper`. |
| Deferred cross-cutting registries | File permission resolution, audit sanitization, notification sender registry, and storage provider registry are recorded here but implemented in Tasks 19–23. |

## Migration sequence

1. Add the failing architecture test and pure behavior tests.
2. Move pure foundation classes and remove Guava-only implementations.
3. Move common security algorithms into split semantic packages; add feature adapters for business callers.
4. Move the Web IP adapter and domain-owned helpers; update every in-repository caller and test.
5. Run the whole-backend architecture, tree, assembler, framework-layout, and service-documentation checks; verify no old imports or empty legacy directories remain.

## Final status vocabulary

- **Retain:** `NameFill`, `NameLookup`, `NameFillExecutor`, feature MapStruct converters, and shared serialization mapper configuration.
- **Migrate:** pure foundation, security algorithm implementations, Web IP adapter, authentication/notification/OA/workflow helpers.
- **Adapt:** business callers of AES/RSA/SHA-256 through feature-owned semantic adapters.
- **Defer:** Task19–23 injected cross-cutting registries and resolvers.
- **Delete:** old `common.utils`, generic authentication/notification/OA support directories, old imports, and aliases.
