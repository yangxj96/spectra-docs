# 版本与支持范围

本页记录当前仓库可以从构建文件、工具配置和源码确认的版本信息。根工作区没有独立发布版本；三个子项目的构建文件、Git 提交和各自发布记录分别是组件版本的事实来源。

## 当前组件版本

- 后端 Maven 根工程的 `revision` 为 `0.0.1-SNAPSHOT`，Spring Boot 为 `4.1.0`，编译目标为 Java 25。
- Web 管理后台 `spectra-ui` 的 package version 为 `0.0.1`，项目为私有应用包，不作为独立 npm 发布包。
- 流程设计器包 `@yangxj96/logicflow-plugin-flowable` 的 package version 为 `0.1.2`，构建产物提供 ESM、CJS 和 TypeScript 声明文件。
- 后端 API 契约版本为 `1.0.0`。

## 运行依赖

后端启动需要可连接的 PostgreSQL 和 Redis。Redis 当前连接配置要求密码认证，并且安全 Redis 是 Token、Session、验证码、防重放和登录失败锁定的事实源。文件上传使用本地存储或 S3 兼容对象存储，选择 S3 时还需要配置 endpoint、access key、secret key、bucket 和 region。

当前部署文档覆盖单机开发、容器、反向代理、HTTPS 和生产部署。没有在仓库中验证的操作系统、数据库、Redis 集群、服务发现、云厂商对象存储或浏览器组合，不写入已支持矩阵。

## API 版本

后端 Controller 当前使用 `1.0.0` API 版本。请求和响应示例、路径和权限说明见 [[后端/10-后端模块/16-API总览|后端接口总览]]。修改 Controller、请求模型或响应模型时，需要同步接口总览和相关使用指南。

## 许可证

三个代码子项目的 package 或项目元数据声明许可证为 Apache-2.0，并各自提交了 `LICENSE` 文件。使用某个子项目时，还需要遵守其依赖树中第三方组件的许可证。

## 如何判断文档是否适用

1. 先确认使用的根仓库提交和三个子模块提交。
2. 再对照本页的工具、组件和 API 版本。
3. 如果文档中的文件路径、命令或页面标题与当前源码不一致，以当前构建文件、源码和迁移文件为准，并提交文档问题。
4. 涉及生产环境的内容还要结合 [[部署运维/04-生产环境部署说明|生产环境部署说明]]、[[部署运维/07-安全备份恢复手册|安全备份恢复手册]] 和实际部署拓扑复核。
