# 接口与配置索引

本页是参考入口，不复制接口或配置的完整内容。阅读具体实现时，优先查看与当前模块和运行环境对应的文档。

## 接口

- [[后端/10-后端模块/16-API总览|后端接口总览]]：按 Controller、路径、版本和用途查看当前 REST API。
- [[后端/10-后端模块/04-用户与权限|用户与权限]]：认证身份、角色、RoleAssignment、Permission 和数据范围。
- [[后端/10-后端模块/09-文件上传|文件上传]]：上传会话、分片、文件资产、业务引用和预览下载。
- [[后端/10-后端模块/10-工作流|工作流]]：表单定义、流程定义、流程实例和任务动作。
- [[后端/10-后端模块/11-统一通知模块|统一通知模块]]：通知请求、模板、渠道、投递和消息中心。
- [[前端/05-前端请求与安全通信|前端请求与安全通信]]：Web 请求封装、刷新、CSRF 和接口加解密边界。

当前 API 契约统一为 `1.0.0`。认证、权限、数据范围和业务状态由后端最终判断，前端文档中的路由和按钮只描述页面行为。

## `spectra:` 配置

- [[后端/40-配置说明/00-后端配置说明|后端配置说明]]：按安全、系统、验证码、文件上传、通知和定时任务逐项说明配置属性、默认值、环境变量和生效范围。
- [[后端/10-后端模块/12-基础设施|后端基础设施]]：Redis、PostgreSQL、缓存、安全和运行时基础设施。
- [[后端/10-后端模块/13-数据库连接池|数据库连接池]]：HikariCP 连接池配置和运行边界。
- [[部署运维/02-容器编排配置|部署配置]]：容器环境中的服务、网络、存储和环境变量组织。
- [[部署运维/03-SSL证书配置|SSL 证书配置]]：本地开发证书和 HTTPS 配置。

`application-*.yml` 中的默认值、环境变量和部署 Secret 共同决定最终配置。本机 `.mise.local.toml`、`.env.development` 和证书文件不属于发布文档内容。
