# 常见命令

> 本页只保存可复用命令。首次配置、环境变量分级和数据库初始化见 [[10-环境搭建]]。

## 命令执行约定

- Windows 命令使用 PowerShell 7.6+ 的 `pwsh`，用 `Get-Command pwsh` 查看本机实际路径。
- 所有路径均为仓库相对路径；不要把个人盘符、用户名目录或 IDE 临时文件写入公共命令。
- `mise.toml`、Maven Wrapper 和 pnpm 脚本可直接复用。
- `.mise.local.toml`、`.env.development`、证书和 Provider 凭据是本机配置，必须先从 `.example` 创建。
- `pnpm install` 只在首次克隆或锁文件变化时执行，不是每次启动步骤。

## 快速检查当前事实

从仓库根目录执行：

```powershell
.\scripts\agent-context.ps1
.\scripts\check-docs.ps1
```

`agent-context.ps1` 和 `check-docs.ps1` 只读取项目事实。`agent-runtime.ps1` 会修改当前 PowerShell 会话的运行时和 Maven 缓存变量，仅用于 mise 未激活或 Agent/CI 沙箱：

```powershell
. .\scripts\agent-runtime.ps1
```

它按以下顺序发现工具和目录：

1. `SPECTRA_AGENT_*` 显式覆盖变量。
2. 当前 `JAVA_HOME` 和 PATH 中的 `java`、`node`、`pnpm`。
3. Codex bundled Node（存在时）。
4. Maven 仓库优先使用可写的用户 `.m2/repository`，否则使用仓库内已忽略的 `.maven-repository/`，最后使用临时目录。

普通开发终端只需激活 mise，不需要设置这些 Agent 变量。

## spectra-admin

以下命令从 `spectra-admin/` 执行：

```powershell
# 渐进格式检查与格式化
.\mvnw.cmd spotless:check
.\mvnw.cmd spotless:apply

# 全量格式检查；PowerShell 中系统属性必须作为单个参数
.\mvnw.cmd spotless:check "-Dspotless.ratchetFrom=NONE"

# 测试、编译、打包
.\mvnw.cmd test
.\mvnw.cmd clean compile
.\mvnw.cmd clean package -DskipTests

# 只构建指定模块及其依赖
.\mvnw.cmd clean compile -pl spectra-core -am
```

启动已打包 JAR：

```powershell
$jar = Get-ChildItem .\spectra-launch\target\spectra-launch-*.jar -File |
    Where-Object { $_.Name -notlike '*.jar.original' } |
    Select-Object -First 1
java --add-modules ALL-SYSTEM --enable-native-access=ALL-UNNAMED `
    -Dspring.profiles.active=dev `
    -jar $jar.FullName
```

模板默认使用 HTTPS：

```text
https://127.0.0.1:4004/api/actuator/health
```

后端本机配置必须设置 `SERVER_SSL_ENABLED=true`，并确保 `files/ssl/keystore.p12` 与 `SSL_PASSWORD` 可用。

## spectra-ui

以下命令从 `spectra-ui/` 执行：

```powershell
pnpm install
pnpm start
pnpm run format:check
pnpm run lint
pnpm run type-check
pnpm run test
pnpm run build
pnpm run preview
```

`pnpm start` 的 `prestart` 会执行会写回文件的 `format`、`lint:fix` 和类型检查。CI 或只读审查应使用 `format:check → lint → type-check → test → build`。

## spectra-app

以下命令从 `spectra-app/` 执行：

```powershell
pnpm install
pnpm start
pnpm run dev:mp-weixin
pnpm run format:check
pnpm run lint
pnpm run type-check
pnpm run build:h5
pnpm run build:mp-weixin
```

H5 默认地址为 `https://localhost:5174`，使用与后端相同的本机 P12 证书。微信小程序还需要在本机安装并配置对应开发者工具；IDE 安装位置和小程序 AppID 都是个人/组织配置，不写死在公共文档中。

## logicflow-plugin-flowable

以下命令从 `logicflow-plugin-flowable/` 执行：

```powershell
pnpm install
pnpm run format:check
pnpm run build
pnpm run dev
```

修改插件源码并与 Web 联调时，保持 `pnpm run dev` 监听，再在另一个终端启动 `spectra-ui`。普通 Web 开发只需使用已经构建的插件产物。

## 一次检查四个工程

从仓库根目录分项目执行，避免混淆工作目录：

```powershell
Push-Location .\spectra-admin
.\mvnw.cmd spotless:check
.\mvnw.cmd test
Pop-Location

Push-Location .\logicflow-plugin-flowable
pnpm run format:check
pnpm run build
Pop-Location

Push-Location .\spectra-ui
pnpm run format:check
pnpm run lint
pnpm run type-check
pnpm run test
pnpm run build
Pop-Location

Push-Location .\spectra-app
pnpm run format:check
pnpm run lint
pnpm run type-check
pnpm run build:h5
Pop-Location
```

## 停止开发服务

优先在对应启动终端按 `Ctrl+C`。只有确认端口确实由本次开发服务占用后，才终止 PID：

```powershell
$ports = @(4004, 5173, 5174)
$listeners = Get-NetTCPConnection -State Listen -ErrorAction SilentlyContinue |
    Where-Object { $_.LocalPort -in $ports } |
    Select-Object LocalPort, OwningProcess

$listeners | Format-Table -AutoSize
```

确认清单无误后再执行：

```powershell
$listeners.OwningProcess | Sort-Object -Unique | ForEach-Object {
    Stop-Process -Id $_ -Force
}
```

## CodeGraph（可选）

CodeGraph CLI 已安装并加入 PATH 时：

```powershell
codegraph explore "要查询的符号或问题"
```

未安装时跳过；源码构建、测试和项目启动都不依赖 CodeGraph。不要在公共文档中记录某台机器的 `codegraph.exe` 或 `codegraph.cmd` 绝对路径。

## VS Code

`spectra-ui`、`spectra-app` 和 `logicflow-plugin-flowable` 提交了相对工作区的 `.vscode/launch.json` 与 `.vscode/tasks.json`，并通过 PATH 中的 `mise.exe` 启动。后端当前没有公共 `.vscode/launch.json`，使用本页的 Maven + JAR 流程，或在个人 IDE 中建立不提交的运行配置。

如果 VS Code 找不到 `mise.exe`，修复 VS Code 进程的 PATH 后重开窗口；不要把个人 mise 安装绝对路径提交进 `.vscode`。

## Git

提交、暂存、恢复和推送遵循项目 `spectra:git-execution-spec`。常用提交格式：

```text
type(scope): 中文描述
```

不要提交 `.mise.local.toml`、`.env*` 本机覆盖、证书、私钥、Token、密码、`.maven-repository/` 或构建产物。
