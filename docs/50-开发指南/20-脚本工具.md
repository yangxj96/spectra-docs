# 脚本工具

> 本页只记录当前仓库实际存在的 `scripts/` 工具。旧文档提到的 `toml2env.ps1` 和 SSL 脚本未随仓库提交，不能作为新克隆的启动步骤。

## 可直接使用

以下脚本都从仓库根目录执行，并通过 `$PSScriptRoot` 解析仓库位置，不依赖个人盘符：

| 脚本 | 是否修改文件/环境 | 用途 |
|---|---|---|
| `scripts/agent-context.ps1` | 否 | 输出工具版本、模块数量、验证命令和活动计划 |
| `scripts/check-docs.ps1` | 否 | 校验 wikilink、Entity/Controller 数量和过期文档标记 |
| `scripts/agent-runtime.ps1` | 只修改当前 PowerShell 会话；必要时创建已忽略的本地 Maven 缓存目录 | Agent/CI 沙箱找不到 mise 运行时时的回退 |

```powershell
.\scripts\agent-context.ps1
.\scripts\check-docs.ps1
```

`agent-runtime.ps1` 必须点源，才能让环境变量留在当前会话：

```powershell
. .\scripts\agent-runtime.ps1
```

## 本机覆盖变量

脚本优先识别以下可选变量，不在仓库中保存具体绝对路径：

| 变量 | 值类型 |
|---|---|
| `SPECTRA_AGENT_JAVA_HOME` | JDK 根目录 |
| `SPECTRA_AGENT_NODE_BIN` | Node 可执行文件所在目录 |
| `SPECTRA_AGENT_PNPM` | pnpm 可执行文件路径 |
| `SPECTRA_AGENT_MAVEN_REPO` | 可写的 Maven 本地仓库目录 |

普通开发终端已经能通过 mise 找到工具时，不要额外配置这些变量。

## 当前没有随仓库提供的脚本

- 没有 `toml2env.ps1`：请直接从 `.mise.local.toml.example` 或 `.env.example` 复制本机配置。
- 没有 `install-ca.ps1`、`generate-cert.ps1`、`uninstall-ca.ps1`：本地 HTTPS 使用 [[40-SSL证书配置]] 中的人工命令，或由团队以后补充经审查的脚本。

文档不得声称不存在的脚本“可直接运行”。新增脚本时应同时更新本页并运行 `.\scripts\check-docs.ps1`。
