# 网站项目文档同步

## 目的

`spectra-docs` 是光谱系统和流程设计器的项目文档源仓库，`yangxj96-website` 是发布网站。网站中的 `docs/pages/blogs/` 由网站仓库独立维护；项目文档和流程设计器文档由同步脚本生成。

同步不会使用 GitHub Actions，也不会自动执行 Git commit 或 push。脚本在本机运行，使用本机已经配置好的 Git/SSH 环境访问两个仓库。

## 文档分区

| 源文档 | 网站目录 | 用途 |
|---|---|---|
| `spectra/docs/` | `website/docs/pages/spectra-admin/` | Spectra 项目文档 |
| `spectra/docs/20-前端/40-流程设计器.md` | `website/docs/pages/logicflow-flowable` | 独立流程设计器文档 |
| `spectra/docs/10-后端/permission-catalog.yaml` | `website/docs/public/spectra-admin/` | 权限目录下载附件 |
| 网站仓库 `docs/pages/blogs/` | 保持原位置 | 个人博文，不参与同步 |

普通项目 Markdown 默认全量同步。模板、计划模板和 Agent 设计/计划产物不作为网站页面；明确列出的 YAML 文件作为附件同步。`.mise.local.toml`、`.env*`、私钥、Token、密码和证书私钥永不复制。

## 脚本命令

脚本位置：`scripts/sync-website-docs.ps1`。

### 预览变更

```powershell
$website = '<website-repo-path>'

pwsh .\scripts\sync-website-docs.ps1 `
  -WebsiteRoot $website `
  -Mode Preview
```

Preview 只生成临时结果并输出新增、修改、删除列表，不修改 website 文件。

### 首次迁移

确认 Preview 输出后，执行一次旧项目页面清理和构建：

```powershell
$website = '<website-repo-path>'

pwsh .\scripts\sync-website-docs.ps1 `
  -WebsiteRoot $website `
  -Mode Apply -PruneLegacy -Build
```

`-PruneLegacy` 只清理 `spectra-admin`、`logicflow-flowable` 和项目附件生成目录，不会触碰 `blogs`。

### 日常同步

```powershell
$website = '<website-repo-path>'

pwsh .\scripts\sync-website-docs.ps1 `
  -WebsiteRoot $website `
  -Mode Apply -Build
```

日常运行使用上一次生成的清单删除源仓库已移除的页面。

如果上一次同步已经 Apply 但尚未在 website 仓库提交，脚本默认会拒绝覆盖生成目录。确认这些差异全部来自同步脚本后，可以显式允许再次生成：

```powershell
$website = '<website-repo-path>'

pwsh .\scripts\sync-website-docs.ps1 `
  -WebsiteRoot $website `
  -Mode Apply -AllowDirtyProjectDocs -Build
```

不要使用该参数覆盖项目目录中的手工修改。

## 检查 website 差异

由于 website 是私有仓库，Git 可能需要在当前命令中声明本机目录为安全仓库：

```powershell
$website = '<website-repo-path>'
$safe = 'safe.directory=' + $website.Replace('\', '/')

git -c $safe -C $website status --short --branch
git -c $safe -C $website diff --stat -- docs/pages/spectra-admin docs/pages/logicflow-flowable docs/public/spectra-admin docs/.vitepress/generated
git -c $safe -C $website diff -- docs/pages/blogs
pnpm --dir $website run docs:build
```

项目文档差异确认无误、博客差异为空后，再在 website 仓库中手动 commit 和 push。

## 可复用提示词

以后可以把下面的提示词直接发送给 Codex：

```text
请执行一次 Spectra 项目文档到个人网站的本地同步。

源仓库：当前 Spectra 工作区根目录
网站仓库：<website-repo-path>

要求：
1. 先检查两个仓库的工作区状态；
2. 执行 scripts/sync-website-docs.ps1 的 Preview；
3. 展示新增、修改、删除的项目文档；
4. 确认 website/docs/pages/blogs 没有任何变更；
5. 确认无误后再执行 Apply 和 VitePress 构建；
6. 项目文档同步到 website/docs/pages/spectra-admin；
7. 流程设计器文档同步到 website/docs/pages/logicflow-flowable；
8. 权限目录等附件同步到 website/docs/public/spectra-admin；
9. 允许同步安全手册、备份恢复、应急操作和内部开发笔记；
10. 不读取或复制 .mise.local.toml、.env、私钥、Token、密码或证书私钥；
11. 不修改 blogs，不自动 commit，不自动 push；
12. 最后报告同步结果、构建结果和 website git diff。
```
