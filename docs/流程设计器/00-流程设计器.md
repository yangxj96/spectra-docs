# 流程设计器知识地图

> 流程设计器由独立 npm 插件 `@yangxj96/logicflow-plugin-flowable` 和 `spectra-ui` 宿主页面组成。插件负责画布建模与 BPMN XML 转换，宿主负责业务选择器、流程定义接口和部署操作，后端负责持久化、部署和流程运行。

## 三层边界

```text
logicflow-plugin-flowable
  ├─ LogicFlow 插件注册
  ├─ BPMN 节点、边和连接规则
  ├─ DND 面板、属性面板、右键菜单
  ├─ 流程上下文
  └─ BPMN XML import / export

spectra-ui
  ├─ WorkflowDesigner 页面和三栏布局
  ├─ form / user / group / javaClass / process Picker
  ├─ 加载已有流程资源
  └─ 调用 WorkflowApi 部署流程

spectra-admin + Flowable
  ├─ 流程定义和版本
  ├─ BPMN XML 部署
  ├─ 流程实例和任务运行
  └─ 后端权限、事务和业务数据
```

## 当前能力边界

当前插件实际提供：

- 5 类事件、4 类任务、3 类网关、2 类子流程/调用活动和 1 类序列流。
- LogicFlow 插件注册、节点渲染、拖拽面板、属性面板和节点/边右键菜单。
- 流程级、节点级和连线级属性 Schema。
- Flowable 扩展属性、表达式、脚本 CDATA 和文档说明。
- BPMN XML 导入、导出、重复属性清理、ID 规范化、BPMN DI 坐标及路径点恢复。
- `property:picker` 事件，把业务选择交给宿主实现。

当前插件不负责：

- 流程定义的保存、版本管理、发布审批和后端权限。
- 用户、部门、表单、Java 类和流程定义选择器的弹窗或 API。
- 保存/部署前的完整流程图校验。当前源码主要执行连线创建阶段的拓扑规则。
- BPMN 全量元素建模，例如 Pool、Lane、Message Flow、事件网关和复杂网关。
